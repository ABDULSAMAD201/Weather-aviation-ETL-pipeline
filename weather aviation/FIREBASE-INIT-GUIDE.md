# Quick Reference - Firebase Init Answers

## Current Step: Firebase Init

### Selection Screen (Features)
Use arrow keys to navigate, Space to select:
- Select: ☑ Firestore
- Select: ☑ Functions
- Press Enter

---

### Question 1: Which project?
```
? Please select an option:
  > Use an existing project
```
**Answer:** Use an existing project (press Enter)

---

